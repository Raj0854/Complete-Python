## 1. Introduction to Built-in Modules

For example:

- Mathematical calculations
- Random number generation
- Date and time operations

- Operating system interaction
- Working with Python interpreter information
- Advanced collection operations

These modules are part of Python's Standard Library.

### Common Standard Library Modules

| Module | Purpose |
|---|---|
| math | Mathematical calculations |
| random | Random values |
| os | Operating system operations |
| sys | Python interpreter information |
| datetime | Date and time |

## 2. math Module

The `math` module provides mathematical functions and constants.

### Importing math

```python
import math
```

### 2.1 Square Root

```python
import math

print(math.sqrt(25))
print(math.sqrt(144))
```

Output:

```text
5.0
12.0
```

### 2.2 Power

```python
import math

print(math.pow(2, 3))
print(math.pow(5, 2))
```

Output:

```text
8.0
25.0
```

Note: `math.pow()` returns a floating-point number. The `**` operator can also be used for exponentiation.

### 2.3 Ceiling and Floor

`ceil()` rounds a number upward to the nearest integer.

`floor()` rounds a number downward to the nearest integer.

```python
import math

print(math.ceil(4.2))
print(math.floor(4.8))
```

Output:

```text
5
4
```

### 2.4 Factorial

Factorial of a positive integer is the product of all positive integers up to that number.

Example:

5! = 5 × 4 × 3 × 2 × 1 = 120

```python
import math

print(math.factorial(5))
print(math.factorial(6))
```

Output:

```text
120
720
```

### 2.5 Absolute Value

```python
import math

print(math.fabs(-15))
print(math.fabs(25))
```

Output:

```text
15.0
25.0
```

Note: Python's built-in `abs()` is also available and commonly used.

### 2.6 Greatest Common Divisor

`gcd()` returns the greatest common divisor of integers.

```python
import math

print(math.gcd(12, 18))
print(math.gcd(24, 36))
```

Output:

```text
6
12
```

### 2.7 Constants

```python
import math

print(math.pi)
print(math.e)
```

Output:

```text
3.141592653589793
2.718281828459045
```

### 2.8 Trigonometric Functions

```python
import math

angle = math.radians(30)

print(math.sin(angle))
print(math.cos(angle))
print(math.tan(angle))
```

Output will be approximately:


`sin()`, `cos()` and `tan()` expect angles in radians, not degrees.

## 3. random Module

The `random` module generates pseudo-random values.

It is useful for:

- Games
- Simulations
- Random selections
- Testing
- Randomized data generation

Import:

```python
import random
```

### 3.1 randint()

Generates a random integer between the given boundaries, including both boundaries.

```python
import random

number = random.randint(1, 10)

print(number)
```

Output: Any integer from 1 to 10.

### 3.2 randrange()

Selects a random number from a range.

```python
import random

print(random.randrange(1, 20, 2))
```

Possible output:

```text
7
```

The selected number follows the sequence generated by `range(1, 20, 2)`.

### 3.3 random()

Returns a floating-point number greater than or equal to 0 and less than 1.

```python
import random

print(random.random())
```

Possible output:

```text
0.735182
```

### 3.4 uniform()

Returns a random floating-point number between two boundaries.

```python
import random

print(random.uniform(10, 50))
```

Possible output:

```text
32.45821
```

### 3.5 choice()

Selects one random item from a sequence.

```python
import random

colors = ["Red", "Green", "Blue", "Yellow"]

print(random.choice(colors))
```

Possible output:

```text
Green
```

### 3.6 choices()

Selects multiple items. By default, selection is with replacement, so an item can appear more than once.

```python
import random

names = ["Raj", "Aman", "Rohit", "Karan"]

print(random.choices(names, k=3))
```

Possible output:

```text
['Raj', 'Karan', 'Raj']
```

### 3.7 sample()

Selects multiple unique items without replacement.

```python
import random

numbers = [10, 20, 30, 40, 50]

print(random.sample(numbers, 3))
```

Possible output:

```text
[20, 40, 10]
```

### 3.8 shuffle()

Randomly changes the order of elements in a mutable sequence.

```python
import random

numbers = [1, 2, 3, 4, 5]

random.shuffle(numbers)

print(numbers)
```

Possible output:

```text
[3, 1, 5, 2, 4]
```

Important: `shuffle()` modifies the original list and returns `None`.

### 3.9 seed()

`seed()` initializes the pseudo-random generator.

It allows repeatable results when using the same seed and the same sequence of random operations.

```python
import random

random.seed(10)

print(random.randint(1, 100))
print(random.randint(1, 100))
```

Running the same code again with the same Python implementation produces the same sequence.

**Security Note:** Do not use the `random` module for passwords, authentication tokens or security-sensitive values. Use `secrets` for those tasks.

```python
    print("Dice Result:", dice)
```

### Practical Program – Folder Organizer

Create a program that organizes files into folders based on file extensions.

```python
import os
import shutil

source_folder = "Downloads"

if not os.path.isdir(source_folder):
    print("Source folder not found")

else:

    for filename in os.listdir(source_folder):

        file_path = os.path.join(source_folder, filename)

        if os.path.isfile(file_path):

            extension = os.path.splitext(filename)[1]

            if extension:
                folder_name = extension[1:].upper()
            else:
                folder_name = "NO_EXTENSION"

            destination_folder = os.path.join(
                source_folder,
                folder_name
            )

            os.makedirs(destination_folder, exist_ok=True)

            shutil.move(
                file_path,
                os.path.join(destination_folder, filename)
            )

    print("Files organized successfully")
```

**Important:** This program moves files. Test it using a separate sample folder containing copied files before using it on real data.

| Code | Meaning |
|---|---|

| %I | Hour (12-hour format) |
| %M | Minute |
| %S | Second |
| %A | Full weekday |
| %B | Full month name |
| %p | AM/PM |

```text

```

### Practical Program – Age Calculator

```python
import datetime

birth_date = input("Enter date of birth (DD-MM-YYYY): ")

try:

    dob = datetime.datetime.strptime(
        birth_date,
        "%d-%m-%Y"
    ).date()

    today = datetime.date.today()

    if dob > today:
        print("Date of birth cannot be in the future")

    else:

        age = today.year - dob.year

        if (today.month, today.day) < (dob.month, dob.day):
            age -= 1

        print("Your age is:", age)

except ValueError:

    print("Invalid date format")
```

## 9. collections Module

The `collections` module provides specialized container data types.

We will explore four useful tools:

1. Counter
2. defaultdict
3. deque
4. namedtuple

### 9.1 Counter

`Counter` counts how many times each item appears.

```python
from collections import Counter

numbers = [1, 2, 2, 3, 3, 3, 4, 4]

result = Counter(numbers)

print(result)
```

Output:

```text
Counter({3: 3, 2: 2, 4: 2, 1: 1})
```

Get the count of a particular item:

```python
print(result[3])
```

Output:

```text
3
```

Get the most common items:

```python
print(result.most_common(2))
```

Possible output:

```text
[(3, 3), (2, 2)]
```

### Practical Example – Character Frequency

```python
from collections import Counter

text = "programming"

frequency = Counter(text)

for character, count in frequency.items():
    print(character, ":", count)
```

### 9.2 defaultdict

A `defaultdict` provides a default value when a missing key is accessed.

Normal dictionary example:

```python
data = {}

data["Python"].append("Raj")
```

This raises a `KeyError` because the key does not exist.

Using defaultdict:

```python
from collections import defaultdict

data = defaultdict(list)

data["Python"].append("Raj")
data["Python"].append("Aman")

data["Java"].append("Rohit")

print(dict(data))
```

Output:

```text
{'Python': ['Raj', 'Aman'], 'Java': ['Rohit']}
```

Other useful default factories:

```python
from collections import defaultdict

counts = defaultdict(int)

counts["Python"] += 1
counts["Python"] += 1

print(dict(counts))
```

Output:

```text
{'Python': 2}
```

### 9.3 deque

`deque` means double-ended queue.

It allows efficient insertion and removal from both ends.

```python
from collections import deque

numbers = deque([10, 20, 30])

numbers.append(40)
numbers.appendleft(5)

print(numbers)
```

Output:

```text
deque([5, 10, 20, 30, 40])
```

Remove from the right:

```python
numbers.pop()
```

Remove from the left:

```python
numbers.popleft()
```

### Practical Example – Recent Activity

```python
from collections import deque

recent_activity = deque(maxlen=3)

recent_activity.append("Login")
recent_activity.append("Opened Dashboard")
recent_activity.append("Viewed Profile")
recent_activity.append("Updated Profile")

print(recent_activity)
```

Output:

```text
deque(['Opened Dashboard', 'Viewed Profile', 'Updated Profile'], maxlen=3)
```

When the maximum length is reached, adding a new item automatically discards an item from the opposite end.

### 9.4 namedtuple

`namedtuple` creates tuple-like objects whose values can be accessed using meaningful field names.

```python
from collections import namedtuple

Student = namedtuple("Student", ["name", "age", "marks"])

student1 = Student("Raj", 21, 90)

print(student1.name)
print(student1.age)
print(student1.marks)
```

Output:

```text
Raj
21
90
```

Named tuples are immutable, like regular tuples.

## 13. Practical Project – Python System Information Tool

Create a small program that displays information about the computer and Python environment.

### File: system_info.py

```python
import os
import sys
import platform
import datetime


def show_python_info():

    print("\nPYTHON INFORMATION")

    print("Python Version:", sys.version)
    print("Python Executable:", sys.executable)


def show_system_info():

    print("\nSYSTEM INFORMATION")

    print("Operating System:", platform.system())
    print("System Release:", platform.release())
    print("Machine:", platform.machine())
    print("Processor:", platform.processor())


def show_directory_info():

    print("\nDIRECTORY INFORMATION")

    print("Current Directory:", os.getcwd())

    print("Files and Folders:")

    for item in os.listdir():
        print("-", item)


def show_date_time():

    print("\nDATE AND TIME")

    now = datetime.datetime.now()

    print("Date:", now.strftime("%d-%m-%Y"))
    print("Time:", now.strftime("%H:%M:%S"))


def main():

    print("===== PYTHON SYSTEM INFORMATION TOOL =====")

    show_python_info()
```

## 14. Mini Project – Python Utility Toolkit

Build a menu-driven application that combines multiple standard library modules.

### Project Structure

```text
PythonUtilityToolkit/
│
└── main.py
```

### File: main.py

```python
import math
import random
import datetime
import calendar
import statistics
from collections import Counter


def math_tools():

    number = float(input("Enter a number: "))

    if number < 0:
        print("Square root is not available for negative numbers")
    else:
        print("Square Root:", math.sqrt(number))

    print("Absolute Value:", abs(number))
    print("Ceiling:", math.ceil(number))
    print("Floor:", math.floor(number))


def random_tools():

    print("\n1. Generate Random Number")
    print("2. Select Random Item")
    print("3. Shuffle List")

    choice = input("Enter choice: ")

    if choice == "1":

        print(random.randint(1, 100))

    elif choice == "2":

        items = ["Python", "Java", "C++", "JavaScript"]

        print(random.choice(items))

    elif choice == "3":

        items = [10, 20, 30, 40, 50]

        random.shuffle(items)

        print(items)

    else:

        print("Invalid choice")


def date_tools():

    today = datetime.date.today()

    print("Current Date:", today)

    future_date = today + datetime.timedelta(days=30)

    print("Date After 30 Days:", future_date)


def calendar_tools():

    year = int(input("Enter year: "))
    month = int(input("Enter month (1-12): "))

    if 1 <= month <= 12:
        print(calendar.month(year, month))
    else:
        print("Invalid month")


def statistics_tools():

    numbers = [10, 20, 30, 40, 50, 50]

    print("Numbers:", numbers)
    print("Mean:", statistics.mean(numbers))
    print("Median:", statistics.median(numbers))
    print("Mode:", statistics.mode(numbers))


def counter_tools():

    text = input("Enter text: ")

    result = Counter(text)

    print("Character Frequency:")

    for character, count in result.items():
        print(repr(character), ":", count)


def main():

    while True:

        print("\n===== PYTHON UTILITY TOOLKIT =====")

        print("1. Math Tools")
        print("2. Random Tools")
        print("3. Date Tools")
        print("4. Calendar Tools")
        print("5. Statistics Tools")
        print("6. Character Counter")
        print("7. Exit")

        choice = input("Enter choice: ")

        if choice == "1":
            math_tools()

        elif choice == "2":
            random_tools()

        elif choice == "3":
            date_tools()

        elif choice == "4":
            calendar_tools()

        elif choice == "5":
            statistics_tools()

        elif choice == "6":
            counter_tools()

        elif choice == "7":
            print("Toolkit Closed")
            break

        else:
            print("Invalid choice")


if __name__ == "__main__":
    main()
```
