
# Day 1 – Introduction to Programming & Python (Practical)

**Level:** Beginner  
**Category:** Practical & Coding Exercises

## Objective
Is Day mein student Python installation verify karega, development environment setup karega aur basic Python programs execute karega.

---

## 1. Verify Python Installation

**Task:** Check karo ki system mein Python properly install hai ya nahi.

**Commands:**
```bash
python --version
pip --version
```

**Expected Result:** Installed Python aur pip ka version display hona chahiye.

## 2. Setup VS Code

**Tasks:**
- Install VS Code.
- Install Python Extension.
- Create a project folder.
- Select Python Interpreter.
- Open integrated terminal.

## 3. Create First Python File

**Task:** `hello.py` naam ki file create karo.

**Code:**
```python
print("Hello World")
```

**Expected Output:**
```text
Hello World
```

## 4. Practice print() Function

**Task:** Different types of values print karna seekho.

**Code:**
```python
print("My Name is Raj")
print(100)
print(25.5)
print(True)
```

## 5. Print Multiple Values

**Task:** Multiple values ek hi print statement mein display karo.

**Code:**
```python
print("Python", "Java", "C++")
```

## 6. Practice sep Parameter

**Task:** Different values ke beech custom separator use karo.

**Code:**
```python
print("2026", "11", "03", sep="-")
```

**Expected Output:**
```text
2026-11-03
```

## 7. Practice end Parameter

**Task:** Multiple print statements ka output same line mein display karo.

**Code:**
```python
print("Hello", end=" ")
print("World")
```

**Expected Output:**
```text
Hello World
```

## 8. Practice Comments

**Task:** Python program mein comments likho.

**Code:**
```python
# Student Information

name = "Raj"
age = 22

print(name)
print(age)
```

## 9. Practice Python Indentation

**Task:** Proper indentation ke saath code execute karo.

**Code:**
```python
if 10 > 5:
    print("10 is greater than 5")
```

## 10. Identify Keywords and Identifiers

**Task:** Given program mein keywords aur identifiers identify karo.

**Code:**
```python
name = "Raj"
age = 22

if age >= 18:
    print(name)
```

**Identify:**
- Keywords
- Identifiers
- Variables
- Operators

---

## 11. Python Shell Practice

**Task:** Python Shell open karke directly commands execute karo.

**Commands:**
```python
10 + 20
50 - 10
5 * 5
100 / 10
```

## 12. Python Script Practice

**Task:** Python file create karke multiple statements execute karo.

**File:** `practice.py`

```python
print("Welcome to Python Training")
```
