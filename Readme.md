
# Python Training for Beginners

A complete, practical-focused Python training program designed for students with zero programming knowledge.

## Course Objective

The objective of this training is to help students understand programming fundamentals, learn Python, develop logical thinking, write clean code, and build real-world applications.

## Learning Approach

- Day 1 includes separate Theory and Practical lessons.
- Day 2 onwards, all lessons are practical-focused.
- Every concept is explained before implementation.
- Students will write and execute code themselves.
- Exercises progress from beginner to advanced.
- Regular assignments and assessments track progress.
- Mini projects help students apply what they learn.

## Course Structure

| Day | Topics | Material |
|---|---|---|
| Day 01 | Programming Fundamentals and Python Introduction | Theory + Practical |
| Day 02 | Python Applications, Installation and Environment Setup | Practical |
| Day 03 | Interpreter, First Program and Python Syntax | Practical |
| Day 04 | Variables and Data Types | Practical |
| Day 05 | Type Conversion and User Input | Practical |

## Training Rules

1. Understand the concept before writing code.
2. Type and execute every example.
3. Do not copy solutions without understanding them.
4. Complete exercises independently.
5. Debug errors before asking for solutions.
6. Maintain a record of completed assignments.

## Requirements

- Computer or laptop
- Python 3
- Visual Studio Code
- Python VS Code Extension
- Basic computer knowledge

## Progress Tracking

Student progress will be evaluated through practical exercises, assignments, coding challenges and projects.
